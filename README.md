# ProjectManagementSystem
A console app that allows you to manage and track hours on project development.

## How to run the application
First, clone the project onto your machine. Then navigate to the project directory with a bash terminal.

To compile the java files to a bin folder, use this bash command:

```bash
javac -d bin *.java 
```

This will compile all the files and leave the class files in one compiled folder

To run the code from this folder, use this bash command:

```bash
java -cp bin Main
```
